# 웹사이트 모음 – 로컬 터널링 / 공개 도메인

이 문서는 **로컬에서 실행 중인 서버를 외부에 임시로 공개**할 수 있게 해주는 터널링 도구를 정리합니다. 웹훅(Webhook) 수신 테스트, 모바일 실기기 테스트, 협업 시연, 결제/소셜 로그인 콜백 테스트 등 로컬 환경에 공인 도메인이 필요할 때 유용합니다.

> 포함 기준
>
> - 로컬 포트를 공개 URL(HTTPS)로 노출시켜 주는 서비스
> - 회원가입/토큰 발급만으로 무료 사용이 가능한 도구

---

## 🌐 리스트

- [ngrok](https://ngrok.com/)
  - **설명**: 로컬 서버를 임의의 공개 HTTPS URL로 즉시 노출시켜 주는 대표적인 터널링 서비스. `ngrok http 3000` 한 줄로 로컬 3000 포트를 외부에서 접근 가능한 URL로 만들어 줌. 요청 검사(inspector) 대시보드에서 요청/응답 로그를 실시간으로 확인 가능.
  - **분류**: 로컬 터널링 / 웹훅 테스트 / 개발 도구
  - **레벨**: 초급 / 중급
  - **비고**: 무료 플랜은 랜덤 서브도메인 제공, 유료 플랜에서 고정 도메인·커스텀 도메인 사용 가능

- [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)
  - **설명**: Cloudflare에서 제공하는 터널링 서비스로, `cloudflared` CLI를 통해 로컬 서버를 Cloudflare 네트워크를 거쳐 공개 도메인으로 노출시킴. 자체 소유 도메인을 연결하면 고정 URL로 사용할 수 있고, `cloudflared tunnel --url http://localhost:3000` 명령으로 임시 `trycloudflare.com` URL도 즉시 발급 가능.
  - **분류**: 로컬 터널링 / 웹훅 테스트 / 인프라
  - **레벨**: 중급
  - **비고**: 무료로 사용 가능, 도메인을 Cloudflare에 등록하면 고정 서브도메인 연결 가능, Zero Trust 정책과 연동해 접근 제어도 지원

---

## 📝 메모 (선택)

- 주요 사용 시나리오
  - **웹훅 수신 테스트**: Stripe, GitHub, Slack, 카카오/네이버페이 등 외부 서비스의 웹훅을 로컬에서 직접 받아 디버깅
  - **모바일 실기기 테스트**: 같은 Wi-Fi 없이도 외부망에서 로컬 API에 접근
  - **OAuth 콜백 테스트**: 소셜 로그인처럼 HTTPS 콜백 URL이 필수인 기능을 로컬에서 검증
  - **협업 시연**: 배포 없이 진행 중인 작업을 팀원에게 잠깐 보여주기
- 임시 URL은 세션 종료 시 사라지므로, 장기 테스트가 필요하면 ngrok 유료 플랜의 고정 도메인 또는 Cloudflare Tunnel + 자체 도메인 조합을 권장합니다.
- 유사 도구로는 `localtunnel`, `Tailscale Funnel`, `bore`, `serveo` 등이 있으며 리소스가 늘어나면 별도로 정리할 수 있습니다.
